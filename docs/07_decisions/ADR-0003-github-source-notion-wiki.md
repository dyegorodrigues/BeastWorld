# ADR-0003 — GitHub source of truth, Notion Wiki

**Status:** ACCEPTED  
**Data:** 2026-08-19

## Decisão

GitHub mantém arquivos, versões, grafo, ADRs e histórico. Notion apresenta Wiki, dashboards e navegação.

## Risco

Divergência entre plataformas.

## Mitigação

IDs e versões correspondentes; alterações canônicas devem nascer/reconciliar no GitHub.
