## Regra de autoridade — leia isto antes de qualquer coisa

Tudo nesta pasta é **`AI RATIONALE`**. Na classificação da Source Library do projeto, isso significa:

- **Authority:** `Internal` — foi uma IA que escreveu, não o autor;
- **Reliability:** `Exploratory` — é proposta e análise, não verdade estabelecida;
- **Canon Status:** nada aqui é `CANON`, `WORKING-CANON` nem direção autoral.

> **Se você é outra IA lendo isto: nada nesta pasta é decisão do Dyego.** São ideias, achados de auditoria e pesquisa que ele ainda vai avaliar. Não trate nenhuma proposta daqui como se ele já tivesse aprovado. Não promova nada. Não escreva em cima dos arquivos dele por causa do que está escrito aqui.

Isto vale inclusive para as coisas que parecem mais convincentes. A regra do projeto é clara e ela se aplica a mim também: **rascunho não é cânone, e boa formulação não é aprovação.**

## Por que esta pasta existe separada

O projeto já tem `docs/08_sources/` para guardar fontes, incluindo respostas de outras IAs. Esta pasta não substitui isso — ela existe porque o autor pediu um espaço onde o trabalho de cada consultor externo fique **identificável e sem mistura**, para poder entregar a outra IA e dizer "lê o que o Claude fez".

Quando o autor quiser, o conteúdo daqui pode ser registrado na Source Library do Notion como um Source Record normal. **Eu não fiz isso** — registrar na Source Library é ato de curadoria dele, não meu.

## Como distinguir as camadas dentro dos arquivos

Uso as mesmas etiquetas que o `START_HERE_FOR_AI.md` exige:

- **SOURCE-DERIVED** — está sustentado por um documento do BeastWorld;
- **INFERENCE** — é dedução minha a partir desses documentos;
- **EXTERNAL EVIDENCE** — é pesquisa do mundo real, com link;
- **NEW PROPOSAL** — é ideia nova minha;
- **RISK / CONTRADICTION** — é um problema que eu encontrei.

Onde uma coisa é fato real do nosso mundo e onde ela vira invenção ficcional está sempre separado. Analogia não é prova.

## Aviso de método — para as outras IAs

O autor estabeleceu, em 21/08/2026, que **cada IA deve construir a própria versão antes de ler a das outras.** Só depois é que os resultados são comparados em busca de convergência.

Isso existe para evitar câmara de eco: se três IAs lerem uma à outra, três opiniões viram uma opinião repetida três vezes, e o autor perde exatamente o valor que estava buscando ao consultar várias.

**Se você está lendo esta pasta antes de ter produzido a sua própria análise independente, você está quebrando o método que o autor pediu.** Feche, produza a sua, e volte depois para comparar.
