# BeastWorld — Decision Provenance Ledger

**Status:** governance / provenance recovery  
**Purpose:** prevent bare letter choices such as `D`, `B+C`, `C+D` from becoming unrecoverable pseudo-decisions.

## Rule from now on

Whenever an agent presents alternatives, the archive must preserve:

1. full question;
2. full wording of every option;
3. author's response;
4. any correction or qualification in the same turn;
5. resulting status (`direction`, `hypothesis`, `open`, etc.).

Use names for architectures whenever possible. Letters may remain as convenience labels only.
