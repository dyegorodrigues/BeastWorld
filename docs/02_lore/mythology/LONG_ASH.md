# Cinza Longa

## Função histórica

Criar uma pressão ecológica plausível para múltiplos Acordos humano-Besta sem depender de “profecia do primeiro escolhido”.

## Requisitos

A crise deve deixar evidência material:

- camadas geológicas;
- lagos antigos;
- cidades abandonadas;
- migrações humanas;
- gargalos populacionais;
- calendários e mitos;
- deslocamentos de espécies.

## Causa

Ainda aberta. Vulcanismo, mudanças oceânicas, incêndios prolongados, impacto climático composto ou outra causa podem ser combinados.

## Regra

Não escolher causa apenas pelo espetáculo. Ela precisa produzir o mundo posterior.
